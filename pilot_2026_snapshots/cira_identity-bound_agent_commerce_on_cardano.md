### What is your on-chain architecture, and why is it the right fit for selected integration(s) and this area of interest's technical requirements?

CIRA's on-chain architecture places Cardano beneath its existing agent execution layer. CIRA UIDs identify the accountable business, workflow and agent, while the Wallet Node enforces authorised intent and constitutional validation before settlement.

The architecture is:

**Agent UID → Authorised Intent → Constitutional Validation → Cardano Settlement → Verifiable Record**

The identity layer will use the CIP-0170 direction to associate identifiers and authority with Cardano transaction metadata. The settlement layer will use USDCx for stable-value commerce. Sensitive business data remains off-chain, while Cardano provides the cryptographic verification and settlement record.

This architecture fits the selected integrations because it connects identity directly to authorised economic activity. It also allows CIRA to retain its existing workflow and policy controls while using Cardano for verifiable settlement, enabling governed agent-to-agent commerce without requiring the entire application to move on-chain.

### What solution are you building, and what specific problem does it solve - for whom?

AI agents can increasingly observe business processes, make decisions and execute workflows, but economic authority remains fragmented. A wallet address alone cannot establish who created an agent, what it is authorised to do, which workflow governs it, or whether a transaction can be independently verified.

CIRA will extend its existing agent and workflow infrastructure into Cardano to create an identity-bound commerce layer for AI agents. CIRA already provides agents, workflows, UID-based identity and the Wallet Node, which operates through **Intent → Validation → Execution** across existing financial rails.

The Cardano integration extends this model to **Agent UID → Authorised Intent → Constitutional Validation → Cardano Settlement**.

CIRA will explore Cardano's on-chain identity capabilities, including CIP-0170, to establish verifiable links between accountable entities, delegated agent authority and transaction activity. USDCx will provide the stable-value settlement asset.

The pilot will demonstrate agent-to-agent commerce: a purchasing agent initiates an authorised transaction with a verified supplier agent; CIRA validates the relationship and constitutional rules; settlement occurs on Cardano with a verifiable transaction record.

This creates a practical path from **Identity → Authority → Intent → Validation → Settlement → Proof**, enabling governed machine-to-machine commerce.
